El programa permite ingresar datos como la cantidad de estudiantes, número de empleados, intervalo de llegada, tiempo promedio de atención y duración de la simulación. Con estos datos, SimPy genera los estudiantes y administra la fila de espera mediante un recurso que representa a los empleados disponibles.

Durante la simulación se registra cuánto tiempo espera cada estudiante, cuántos son atendidos y cuál fue el mayor tiempo de espera. Al finalizar, el programa muestra los resultados y realiza un pequeño análisis para determinar si el tiempo de atención es bueno, moderado o elevado.
